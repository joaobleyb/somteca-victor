# Som de teste

`Carefree.mp3` serve para testar o cadastro de músicas e a aprovação pelo gestor.

| Campo | Valor |
|---|---|
| Título | Carefree |
| Artista | Kevin MacLeod |
| Álbum | qualquer um (ex.: *Lounge & Jazz*) |
| Duração | 3:25 |
| Número da faixa | um número livre no álbum (ex.: 10) |

**Como testar a aprovação:** entre como `ana` (senha `somteca123`) e cadastre a música; ela fica "aguardando aprovação". Depois entre como `demo` (gestor) e clique em **Aprovar** no Painel do Gestor (`/gestor/`).

## Crédito
